# Зайцев-Интерактив 2.0 (Zaytsev-Interactive)

Интерактивный веб-тренажёр английской грамматики по методике Н.А. Зайцева.

**Ключевой принцип: цвет = член предложения.**

## Демо

Просто откройте `index.html` в любом современном браузере. Интернет нужен для шрифтов и Three.js (CDN), но есть локальный запасной вариант.

## Стек

- Чистый HTML + CSS + Vanilla JS (ES6+)
- Three.js — для 3D-конструктора кубиков (CDN + локальный запасной `vendor/three.min.js`)
- Никаких фреймворков, сборщиков или npm

## Возможности

### 0. Карта мира методики (World Map) — панорама
Главный экран — интерактивная карта игрового мира, которая показывает
всю методику одновременно. Девять земель соответствуют девяти таблицам,
внутри каждой клетки разложены как в бумажной таблице (столбцы — формы,
строки — времена или модальные глаголы).

- **Панорама**: все земли видны в одном кадре; карту можно тянуть и
  приближать колесом мыши, кнопками `+` / `−` / `⛶`.
- **Миникарта** показывает текущий обзор и позволяет прыгнуть в любую точку.
- **Маршруты** между землями подписаны логикой перехода: «кто + быть»,
  «действие», «процесс», «результат», «длительность», «возможность»,
  «побуждение», «наличие».
- **Срезы мира**: фильтры по времени (Past / Present / Future), залогу
  (Active / Passive) и цвету члена предложения. Всё, что не попадает в срез,
  притухает — видно, как одна и та же грамматика пронизывает все земли.
- **Поиск клетки по номеру** (1–137): карта приближается к адресу и
  открывает карточку с шаблоном, примером и действиями.
- **Прогресс исследования** сохраняется в localStorage: у каждой клетки
  появляется зелёная отметка, в шапке растёт счётчик, а у земли — свой
  прогресс. Кнопка `↺` сбрасывает исследование.
- **Случайная клетка** — режим путешествия по миру.
- Клик по клетке открывает переходы в таблицу, мастер и конструктор;
  двойной клик по земле приближает её.

### 1. Карта таблиц (Interactive Table Map)
Все 9 таблиц комплекта:
- **Местоимения** — склонение личных местоимений
- **TO BE** — быть (Present, Past, Future)
- **INDEFINITE** — простое время (V, V1, V2)
- **CONTINUOUS** — длительное (am/is/are/were + V-ing)
- **PERFECT** — совершённое (have/has/had + V3)
- **PERFECT CONTINUOUS** — совершённое длительное (have been + V-ing)
- **IMPERATIVE** — повелительное наклонение
- **Модальные глаголы** — can, may, must, should, would, need, ought to
- **THERE** — оборот there is/are/was/were

#### Нумерация клеток

| Диапазон | Раздел |
|----------|--------|
| 1–14 | TO BE |
| 15–43 | INDEFINITE |
| 44–65 | CONTINUOUS |
| 67–96 | PERFECT |
| 97–109 | PERFECT CONTINUOUS |
| 111–116 | IMPERATIVE |
| 118–133 | Модальные глаголы |
| 134–137 | THERE |

Для каждой клетки:
- ✓ Цветной шаблон
- ✓ Пример предложения
- ✗ Альтернатива (вариант с отрицанием / вопросом)
- ✗ Номер клетки
- ✗ Оригинал таблицы (скан JPG)

**Новое:** поиск клетки по номеру — введите номер (1–137) и нажмите Enter или «Найти».

### 2. Мастер алгоритма (Algorithm Wizard)
Пошаговый подбор клетки по методологии Зайцева:
1. Таблица → 2. Актив / Пассив → 3. Точка / Вопрос → 4. Отрицание (not/n't) → 5. Время

На каждом шаге зона поиска сужается, в конце отображается номер и содержимое клетки.

**Новое:** кнопка «↺ Сбросить мастер» — начать определение заново.

### 3. Конструктор кубиков (Cube Builder) — 3D
Флагманский режим. Соберите предложение из цветных кубиков.

- **Красный** (#E53E3E) — кто/что (подлежащее)
- **Синий** (#3182CE) — глагол (сказуемое)
- **Зелёный** (#38A169) — всё остальное (дополнение, место, время)
- **Чёрный** (#1A202C) — отрицание (not, n't, no)
- **Жёлтый** (#D69E2E) — служебные слова (вопросы, артикли, предлоги, to)

Склад: ~260 кубиков из методических материалов.

Механика:
- **3D-сцена** (Three.js): 6 слотов-полок с полупрозрачными рамками.
- **Клик + перетаскивание по полке**: кликните по кубику → потяните вдоль полки → отпустите — кубик встанет в ближайший слот, совместимый по цвету.
- **Короткий клик** по кубику — подсказка.
- **2D-строка под сценой** показывает все слоты с кнопками ✕.
- **Поиск по палитре**: фильтр по названию на русском или английском.
- **Проверка**: структурная (красный + синий = предложение) + процент совпадения с эталоном.
- **Озвучка** собранного предложения (SpeechSynthesis).

**Запасной 2D-режим**: если Three.js недоступен, конструктор работает как плоские цветные карточки.

### 4. Генератор упражнений (Sentence Generator)
Показывает русскую фразу → вы вводите английский перевод. Допускаются вариации:
- `don't` = `do not`
- Лишняя/отсутствующая пунктуация в конце
- Озвучка эталона

Подсказка показывает цветной шаблон клетки и ссылку «Открыть в таблице» или «Собрать в конструкторе».

**Новое:** Ctrl+Enter для быстрой проверки.

## Интерфейс (macOS-стиль)

- **Стеклянные панели** (`backdrop-filter: blur(20px)`)
- **Traffic lights** в левом углу (декоративные красный/жёлтый/зелёный кружок)
- **Плавающий dock** снизу с иконками разделов и переключателем темы
- **Тёмная тема** — кнопка 🌙 в dock, сохраняется в localStorage
- **Адаптив** — на мобильных dock подстраивается

## Как собрать / доработать

1. Добавьте новый словарь кубиков в `js/data/cubes.js` — структура `CUBES` расширяется.
2. Для новых таблиц: `js/data/tables.js` — массив `TABLES`, номер уникален.
3. Для редизайна: `css/tokens.css` (токены) + `css/styles.css` (все селекторы).
